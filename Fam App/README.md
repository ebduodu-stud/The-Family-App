# Family Morning Worship Android app v3

This WebView Android app has a Home screen with previous/next-day controls, all four daily role assignments (including the Bible reader), a Schedule Files section, Participants, and More. Weekly and Monthly screens have been removed.

The schedule is based on the approved family schedule PDF and is split into three-month PDF files (the final available period is May-June 2027). The Home screen shows the daily assignment data.

Daily text pages are loaded from the Twi-language Watchtower ONLINE LIBRARY route where available. The text page is embedded on Home, with a JW Library share-link preferred action and a WOL fallback. Bible references are clickable and use the JW Library share-link format with a WOL fallback. JW Library app-opening behavior depends on Android link handling and the installed app; verify on the target phone.

Build using the existing GitHub Actions workflow.
